# Data Provenance

This directory holds all species parameter files and empirical input data used by the model. Following [CoMSES data management best practices](https://www.comses.net/resources/guides-to-good-practice/) and the [Cornell README metadata guidance](https://data.research.cornell.edu/data-management/sharing/readme/).

## Directory Structure

```text
data/
├── *.csv         # Species parameter files — imported directly by FishCensus.nlogox
├── raw/          # Original, unmodified empirical source data — treat as read-only
└── processed/    # Cleaned or derived inputs ready for model consumption
```

> **Note:** Species parameter CSV files live directly in `data/` (not in `raw/`) because they are model configuration files generated by the FishCensus Species Creator, not raw empirical data. The `raw/` and `processed/` subdirectories are reserved for any external empirical datasets used as inputs (e.g. length-weight coefficients, field survey data).

## Species Parameter Files

All CSV files in `data/` are species parameter sets for use with `code/FishCensus.nlogox`. They are created and edited with `code/FishCensus Species Creator.nlogox` and imported via the **Import Species** button in the main model.

### Baseline and archetype species

| File | Description |
| --- | --- |
| `example.csv` | Default demo species — loaded automatically on first run if no other file is present |
| `calibration.csv` | Baseline calibration species used as the reference for sensitivity analyses |
| `bold.csv` | Species with high diver-attraction tendency |
| `shy.csv` | Species with strong diver-avoidance tendency |
| `indifferent.csv` | Species with no diver reaction |
| `cryptic.csv` | Species with low detectability |
| `not cryptic.csv` | Species with high detectability |
| `schooling.csv` | Schooling species with typical group size |
| `Large schools.csv` | Schooling species with large group size |
| `no schooling.csv` | Solitary species with no schooling behaviour |
| `multispecies.csv` | Multi-species assemblage example |
| `calibration detectability.csv` | Calibration variant — modified detectability parameter |
| `calibration rest.csv` | Calibration variant — modified resting behaviour |
| `calibration school.csv` | Calibration variant — modified schooling parameters |

## FAIR Compliance Notes

- **Findable**: Species parameter files are versioned in this repository. Any future empirical datasets must have a DOI or persistent identifier registered below.
- **Accessible**: This repository is public under the MIT license. Large files (>100 MB) should not be committed to git — archive them on Zenodo or Dryad and link here.
- **Interoperable**: All files are plain CSV (comma or semicolon delimited, configurable via the model's delimiter chooser).
- **Reusable**: Species parameters are fully described by the variable names in the CSV header row. See the ODD protocol at `docs/artifacts/odd/ODD_PROTOCOL.md` for definitions of each parameter.
